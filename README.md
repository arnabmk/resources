# resources
Hi there, welcome! The main objective of creating this repository is to document everything I found interesting and worth sharing related to research in the field of medicinal chemistry, drug discovery, chemical biology and cheminformatics. From my very little experience doing research, what I have realized is that research is all about having a strong desire to make impactful contribution towards the betterment of human being no matter how small or big the contribution is. Whether you are a complete beginner or an independent pro researcher exploring this field I hope this initiative helps.

N.B. While exploring the resources, if you think there is an excellent resource out there (obviously, there are many) which is not included here, please send me a message along with the link and a short description about the resource(s) using this [form](https://forms.gle/bumkXmHNDGzxhW7Y8). I will try to include them asap so that others can be benefited as well! Happy researching and best wishes!

## Essential Database & Webserver 🔗
* [PubTator3](https://www.ncbi.nlm.nih.gov/research/pubtator3/) - AI-powered database for biomedical literature
* [Semantic Scholar](https://www.semanticscholar.org/) - AI-powered scientific literature search engine
* [ChEMBL](https://www.ebi.ac.uk/chembl/) - Database of bioactive molecules with drug-like properties
* [PubChem](https://pubchem.ncbi.nlm.nih.gov/) - Database for accessing chemical information
* [UniProt](https://www.uniprot.org/) - Database of protein sequence and functional information
* [RCSB Protein Data Bank](https://www.rcsb.org/) - Database for accessing experimentally-determined 3D structures of proteins
* [PrankWeb](https://prankweb.cz/) - Machine learning based ligand binding site prediction
* [Clustal Omega](https://www.ebi.ac.uk/jdispatcher/msa/clustalo) - Multiple sequence alignment program
* [ZINC](https://zinc.docking.org/) - Free database of commercially-available compounds for virtual screening
